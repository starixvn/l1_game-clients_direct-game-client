# React + Webpack + Sass + TypeScript Project

This project is a boilerplate setup for building a React application with TypeScript, Webpack, and Sass. The project uses the latest versions of React and TypeScript, and is configured with Webpack for development and production builds.

## Features

- **React** for building user interfaces.
- **TypeScript** for static typing and better development experience.
- **Webpack** for bundling the project and handling different file types.
- **Sass** for styling with `.scss` files.
- Hot Module Replacement (HMR) during development.

## Prerequisites

- [Node.js](https://nodejs.org/) (>= 14.x)
- [Yarn](https://yarnpkg.com/) for dependency management.

## Getting Started

### 1. Install dependencies:
